## Description
This script uses batch files to simulate brute force attacks on Wi-Fi networks. It's designed for educational purposes only.

## Usage
1. Clone the repository: `git clone https:                                     
2. Navigate to the directory: `cd DDOS`
3. Run the script: `Wi-Fi Brute Forcer.bat`

           
* Scans available Wi-Fi networks
* Selects a target network
* Uses a wordlist file to attempt connections
* Displays connection attempts

           
* `help`: Displays this page
* `wordlist`: Provides a wordlist file
* `scan`: Performs a Wi-Fi scan
* `interface`: Opens Interface Management
* `attack`: Attacks the selected Wi-Fi
* `counter`: Sets the attack counter
* `exit`: Closes the program
